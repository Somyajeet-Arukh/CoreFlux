# Contention analysis

`coreflux-analyze` consumes timestamped signal windows and emits one JSON decision per window. Each decision includes a score from 0 to 1, a state, coverage, per-signal contributions, the dominant contributor and whether the state changed. The default normalized weights are CPU pressure 0.35, runnable pressure 0.20, context-switch intensity 0.25, memory pressure 0.10 and scheduler latency 0.10. Five comma-separated weights can be passed as a third argument. Missing signals use `-1`; the scorer renormalizes available weights and reports `UNKNOWN` when less than half the configured weight is available.

The state thresholds are 0.30 for WATCH, 0.60 for CONTENTION and 0.80 for SEVERE. A change needs 0.05 beyond a threshold and at least one second since the previous change. The scorer advances or retreats by at most one level per accepted window. This makes state changes explainable and limits oscillation. Decisions are observe-only; The policy tool can use qualifying decisions for bounded actions.

`sample-signals.py` records CPU and memory pressure from `/proc/pressure`, runnable threads from `/proc/loadavg`, and initial context-switch intensity from `/proc/stat`. `merge-event-intensity.py` replaces the context-switch signal with the event rate from either backend JSONL stream. Scheduler latency is unavailable in the current event model and is explicitly marked missing, giving the default live score 0.90 weight coverage. Signals are host-wide on this WSL kernel and may include activity outside the experiment.

`run-analysis-experiment.sh` repeats a 48-thread CPU workload twice while recording eBPF scheduler events and system pressure. It saves signal windows, decisions and `benchmarks/reports/analysis-reproducibility.json`. In the live experiment, both trials reached CONTENTION with CPU pressure dominant; one also reached SEVERE. The controlled replay and behavior tests separately verify exact transitions, cooldown, hysteresis, custom weights and missing-signal handling. These runs demonstrate a reproducible response to the workload, not calibrated prediction accuracy.
